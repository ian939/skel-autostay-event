# 오토스테이 참여 지점 찾기 (SK일렉링크 제휴 이벤트)

SK일렉링크 × 오토스테이 제휴 프로모션 랜딩페이지. 이벤트에 참여하는 **전국 15개 오토스테이 지점**을 카카오맵에 표시하고, 내 위치 또는 검색한 장소를 기준으로 **가장 가까운 지점을 추천**한다.

빌드 도구 없는 순수 정적 사이트다. HTML + CSS + vanilla JS, npm 의존성 없음.

---

## 배포 전 필수 작업 2가지

### 1. 카카오 JavaScript 키 넣기

`assets/js/config.js`의 `KAKAO_JS_KEY` 값을 교체한다.

```js
var KAKAO_JS_KEY = 'PASTE_KAKAO_JAVASCRIPT_KEY_HERE';  // <- 이 줄
```

키 발급: [developers.kakao.com](https://developers.kakao.com) → 내 애플리케이션 → 앱 키 → **JavaScript 키**

> REST API 키가 아니다. 서로 다른 키다. 이 프로젝트는 지도 렌더링과 장소 검색을 모두
> JavaScript SDK로 처리하므로 REST 키는 필요하지 않다. (정적 페이지에 REST 키를 넣으면
> 그대로 노출되므로 의도적으로 피했다.)

### 2. 사이트 도메인 등록

앱 설정 → **플랫폼 → Web → 사이트 도메인**에 아래 두 개를 등록한다.

```
https://ian939.github.io
http://localhost:8000
```

> **오리진(스킴 + 호스트)만 등록한다.** 리포 경로(`/skel-autostay-event`)를 붙이면 매칭에
> 실패한다. github.io에서 지도가 안 뜨는 사례 대부분이 이 실수다.

또한 앱에 **카카오맵/로컬 서비스가 활성화**되어 있어야 한다. 꺼져 있으면
`App disabled OPEN_MAP_AND_LOCAL service` 403이 발생한다.

## 로컬에서 확인하기

`file://`로 열면 **내 위치와 지도가 동작하지 않는다** (geolocation은 보안 컨텍스트를 요구하고,
`file://`의 오리진은 `null`이라 카카오 도메인 화이트리스트에 매칭되지 않는다).
반드시 HTTP로 띄운다.

```bash
python -m http.server 8000
# http://localhost:8000
```

## 지점 데이터 수정

지점 데이터는 `assets/js/stores.js`에 있지만 **직접 편집하지 않는다.** 자동 생성 파일이다.

원본은 분석 프로젝트에 있다.

| 항목 | 위치 |
|---|---|
| 좌표 | `<분석폴더>/output/지점_좌표.json` (카카오 지오코딩, 29/29 주소 정확매칭) |
| 참여 여부 | `<분석폴더>/오토스테이_..._참여매장표시_260902.xlsx` A열 **노란색 음영** |

지점을 추가·제외하려면 **엑셀에서 음영만 바꾸고** 아래를 실행한다.

```bash
python tools/build_stores.py
```

스크립트가 개수·집계·지역 매핑을 검증하고 `stores.js`를 다시 만든다.
새 지역이 추가되면 `REGION_GROUP`에 매핑을 넣으라고 즉시 실패한다.

현재 구성: **15개** (수도권 12 / 비수도권 3 · 직영 7 / 가맹 8)

```

```

## 동작 방식 메모

- **키가 없거나 지도 로딩이 실패해도 페이지는 동작한다.** 지도 영역에 안내 문구가 뜨고
  지점 목록·혜택·CTA는 그대로 보인다. 흰 화면이 되지 않는다.
- **거리는 직선거리(Haversine, R=6371.0088km)** 다. 실주행거리·소요시간은 별도 API 없이
  계산할 수 없으므로 표기하지 않고, 화면에도 직선거리임을 명시했다.
  분석 프로젝트의 `scripts/haversine.py`와 소수점 6자리까지 일치하도록 이식했다.
- **추천 카드는 지역 필터를 무시하고 항상 전체 중 최근접**을 보여준다. 고양에 있는
  사용자가 대구 필터를 눌렀을 때 추천이 대구로 바뀌면 의미가 없기 때문이다.
- **장소 검색은 키워드 → 주소 폴백**이다. 결과가 여러 개면 사용자가 고르게 한다
  (조용히 첫 결과를 쓰면 엉뚱한 지점을 추천하게 된다).
- `?store=as-01` 쿼리로 특정 지점 딥링크 공유가 가능하다.
- 카카오 검색 응답은 `x`=경도, `y`=위도이며 **문자열**이다. `parseFloat(y), parseFloat(x)`
  순서를 반드시 지켜야 한다.

## 미확정 항목 (배포 전 교체 필요)

페이지에 `[대괄호]`로 남아 있고, **노란색 배경**으로 눈에 띄게 표시된다.

- `[이벤트 기간]`
- 세차 1회권 `[정상가]` / `[할인가]`
- 구독 월 이용료 `[정상가]` / `[할인가]`
- `[쿠폰 유효기간]`, `[n]회` 발급 제한, `[적용 회차]`
- `[쿠폰 발급 경로]`
- CTA 링크 2개 (`혜택 받기`, `앱 다운로드`) — `data-todo` 속성으로 표시

확정 후 값을 채우고, `assets/css/style.css`의 `.todo` 규칙과 마크업의 `class="todo"`를
제거한다. `.todo-link`의 클릭 차단 핸들러(`app.js`)도 함께 정리한다.

찾기: `grep -n 'todo' index.html`
